Each person picks their own copy of the same file. Optionally add a .srt/.vtt subtitle file (local only). Browsers play mp4/webm/m4v best; .mkv works only if its codecs are supported.
Every device streams the link directly from its source, so nothing is relayed through anyone.
Websites can't be remote-controlled by another page, so each person presses play themselves when the countdown hits zero. Many sites refuse to be embedded; if the frame stays blank, use "Open in my own tab" and keep this tab open for the countdown and chat.
